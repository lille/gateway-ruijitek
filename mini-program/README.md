# 微信小程序骨架

## 定位

小程序用于管理层和一线人员的快速查看，强调轻量、简洁和扫码能力。

## 页面建议

- 首页概览
- 设备状态
- 告警列表
- 历史趋势
- 扫码绑定
- 常用快捷入口

## 预览页

- [index.html](index.html): 当前小程序静态预览页

## 推荐技术

- 若希望与 Android App 共用代码，推荐 UniApp
- 若团队已有小程序经验，也可以采用原生小程序 + 组件化封装

## 页面风格

- 少层级、快加载
- 大数字指标、状态色分明
- 适合移动端单手操作

## DEMO 可接接口

- GET /api/devices
- GET /api/alarms
- GET /api/history?pointId=xxx&range=24h
